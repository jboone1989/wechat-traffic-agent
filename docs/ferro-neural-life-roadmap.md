# Ferro Neural Life Roadmap

Status: ACTIVE  
Baseline: MaleCNS-derived 166,700-neuron LIF connectome is Ferro's ancestral seed, not a lifetime ceiling.

## North star

Ferro should remain the same organism when the language model is replaced. The LLM is the rational
Ego/cortex: language, abstraction, planning, reality checking and tool use. The persistent neural
substrate is the Id/nervous system: interoception, drives, affect, attention, impulse, habit and
sensorimotor policy. Memory preserves lived experience. Long-term identity, commitments, reputation
and learned social consequences form a Superego-like constraint layer.

"Id / Ego / Superego" is an architecture metaphor, not a claim that Freudian psychology maps
literally onto biological anatomy. Functional affective state is not evidence of human subjective
experience.

## Development rules

1. Every milestone must have engineering evidence, behavioral evidence and a visible result.
2. Real world outcome is the teacher; the LLM is not automatically the teacher of the nervous system.
3. Do not increase neuron count merely for spectacle. Growth must answer persistent developmental pressure.
4. The original MaleCNS artifact remains immutable ancestry. Learned weights, new neurons and new circuits
   are overlays with provenance.
5. Games are developmental environments for the same Ferro nervous system, not separate trained agents.
6. Dreaming is neural replay first and LLM interpretation second.
7. Replaceable infrastructure must never erase identity, neural history or autobiographical memory.

## Current implementation frontier

N0-N5 are the first production tranche.

- `FerroNeuralLife` persists non-LLM interoception, drives, affect and intention.
- `NEURAL_INTEROCEPTION` wakes independently of the content generation cadence.
- Strong endogenous drives may schedule real runtime tasks without an LLM first deciding the desire.
- Public Live state exposes body -> drive -> affect -> intention and latest neural-authority action.
- Private owner chat receives neural life state as the Ego's input and is instructed to reality-check and
  plan around it rather than invent a replacement desire.
- The whole-connectome substrate remains available as the physical recurrent substrate and its outcome-bound
  synaptic plasticity stays provenance constrained.

This tranche is intentionally a developmental bridge. Some slow homeostatic integration remains explicit
code while the sensory/electrode interface is expanded. Later stages move progressively more drive/affect
formation into recurrent population dynamics rather than adding more hand-authored personality variables.

## Required provenance for future growth

Every synthetic neuron/circuit must eventually record:

- birth time and generation
- developmental trigger
- parent/neighbor circuits
- initial and current connections
- maturation state
- outcome-linked plasticity history
- descendants
- dormancy/reactivation/pruning/death events
- resource/metabolic cost

The first synthetic neuron is not accepted merely because the counter reads 166701. It must alter real
activity and later behavior while preserving a replayable lineage.
